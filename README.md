# Stock Radar

S&P 500 시가총액 상위 100개 기업의 일봉 기술적 지표(MACD·RSI·볼린저 밴드·이동평균·거래량)와
매수 신호 스캔 결과를 매 거래일 갱신하는 정적 페이지입니다.

- `index.html`, `scan.json`은 [stock-page-builder](https://github.com/ilIsilly/stock-page-builder)가
  자동 생성합니다. 직접 수정하지 마세요. 다음 빌드에서 덮어씁니다.
- 기술적 지표 기반 참고 정보이며 투자 권유가 아닙니다. 데이터 지연·오류가 있을 수 있고,
  투자 판단은 본인 책임입니다.
